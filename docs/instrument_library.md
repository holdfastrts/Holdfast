# The owner's sound and instrument library

The owner (2026-11-14): "this library of instruments should be saved for other game projects in the future". This is
the catalogue: every instrument and sound source he has supplied, where it is in this repository, and its licence.
It is now its own repository, **cavaleirobrancopensante/sound-library** (sorted by instrument and kind, with the full
MuldjordKit drum kit): new sounds go there too.

**Licences.** The owner (2026-11-14): every downloaded file is from **Pixabay** (the "freesound_community" names are
Pixabay's account for sounds moved over from freesound): Pixabay Content Licence, commercial use, no credit. CC0 needs
nothing; CC BY (the drum kit) needs the credit line.
