# The owner's sound and instrument library

The owner (2026-11-14): "this library of instruments should be saved for other game projects in the future". This is
the catalogue: every instrument and sound source he has supplied, where it is in this repository, and its licence.
The plan is to copy it into its own repository (organised by instrument, with this catalogue as its README) so other
projects can use it.

**Licence warning before reusing anything.** CC0 and the Pixabay Content Licence allow use in a commercial game with no
credit. CC BY needs the credit line. **Freesound files each carry their own licence** (CC0, CC BY, or CC BY-NC, which
forbids commercial use): check every freesound file's page before it goes into a game you will sell. Files marked
"check" below have no recorded licence yet.
