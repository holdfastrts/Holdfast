# Figure library (owner, 2026-11-13)

Single figures and groups painted by ChatGPT, each alone on flat magenta (RGB 255, 0, 255), in the oil-painting style of
the main menu painting. They are composed into the main menu painting (tools/menu_fix_layers.py "sprite" layers in
art/menu_fix/layers.json, keyed with tools/hub_key.py) and kept as a library for campaign stills, hubs and references.
Name: <faction>_<subject>.png. Prompts: in the chat of 2026-11-13 (P1-P8); the shared form: "Paint, in EXACTLY the
oil-painting style ... of image N, ONE ... facing ..., the background ONE flat solid colour, pure magenta RGB 255, 0, 255
... Landscape 1536 x 1024 pixels, PNG."
